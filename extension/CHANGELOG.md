# 变更记录

本文件记录 CodeTrail 的版本变更；VS Code Marketplace 与 GitHub Releases 使用同一份版本号。

## 0.5.0（2026-11-08）

### 新增

- **C / C++ 语法索引**：支持 C（`.c`、`.h`）与 C++（`.cpp`、`.cc`、`.cxx`、`.c++`、`.hpp`、`.hh`、`.hxx`、`.h++`）；`.h` 默认按 C++ 解析，失败时回退到 C。只把函数定义建为节点，原型不是节点。
- **C 静态关系解析**：同文件词法调用、本地引号 `#include` 文件，以及被包含头文件对应的同目录实现文件；这些静态候选边标记为 `c-include-static`。
- **C++ 静态关系解析**：在 C 的基础上，额外解析 `this->method()`、同一类内的非限定兄弟方法，以及唯一的 `Class::method` 候选。
- VS Code Marketplace 发布准备（publisher `wwwh7`），与 GitHub Releases 并行分发；本轮 Marketplace 发布按计划暂缓，当前请使用 Releases 中的 VSIX。预编译包仍为 Windows x64 目标。

### 修复

- 修复合法 TypeScript `abstract` 属性/方法被 tree-sitter 误报为解析恢复的问题（等长掩码重试，仅采用无错误的重试语法树，名称、签名与哈希仍来自原始源码）。
- 文件诊断现在附带首个错误/缺失节点的 1-based `path:line:col:`，便于定位不完整索引位置。

### 改进

- “分析边界”可见性：统计区与顶栏可查看不完整文件数、未纳入图调用的按原因聚合，以及下一步建议。
- 审核队列降噪：匿名回调 `<callback@…>` 变更默认折叠并可展开，跨重渲染保留状态。
- 无说明函数回退为真实函数名并去重；检查器明确显示“未生成职责说明”。
- 统计文案改为“未纳入图的调用”；点击查看原因分布。
- 扁平仓库的模块视图按文件分组兜底，并支持进入文件层级。
- CLI `--help` 为顶层子命令、query 与 memory 操作补齐中文说明。

### 边界

- C/C++ 解析是静态语法索引：没有 clang/类型检查器集成；对象/指针上的成员调用、函数指针调用需要类型信息，会以明确原因保持未解析（属于静态缺口，不是源码错误）。系统头文件视为外部依赖，不展开解析。

## 0.4.0（2026-11-08）

首个公开版本：Rust 静态分析 CLI、自包含交互式 HTML、VS Code 扩展、Agent Skill 与只读 MCP 工具。支持 TS/TSX/JS/JSX、Svelte script、Python、Go 的语法索引；提供模糊函数搜索、调用方/被调用方网络、Git 修改影响审查、BYOK 职责叙述与有界架构记忆。预编译产物通过 GitHub Releases 分发（Windows x64 VSIX / Skill / 源码包）。
